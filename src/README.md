# src

| Folder | Contents |
| --- | --- |
| `corpus/` | Corpus v1: seed selection, probes, entity lists, collectors, shared matching rules, gazetteer, object linking, snapshot and data card. Run modules with `uv run python -m src.corpus.<module>`; the order is in `scripts/build_corpus.sh` |
| `graph/` | Knowledge graph v1: the core Wikidata layer (decision 0020); later edge layers (decision 0006). Run with `uv run python -m src.graph.core_graph` |
| `explorer/` | Files the interface's atlas and graph views read (decision 0025): coordinates from the raw Wikidata responses, degrees, display hubs, communities (with what each holds and where it lies, decision 0035). Run with `uv run python -m src.explorer.build`; `commons_images` fetches entities' Commons photographs with their credit and licence (decision 0034); `commons_images` fetches entities' Commons photographs with their credit and licence (decision 0034) |
| `coverage_audit/` | Coverage audit (decisions 0031, 0032): fetches the official monument lists (ASI, Karnataka, Madhya Pradesh) untouched with their checksums, and parses each into one row per entry (and UNESCO's list of intangible heritage for India), checked against the list's own totals. Then draws the seeded sample and builds the author's matching sheet with Wikidata candidates. After the author's matching, `.fill` fetches what Wikidata holds for each match and computes the coverage rates. `uv run python -m src.coverage_audit.sources`, then `.lists`, then `.sample`, then `.fill`; `.recheck sheet` and `.recheck agreement` for the blind second pass on 10% of the matches |
| `queries/` | Benchmark queries (decision 0021): the grid of information needs, the fixed generation prompts, the generator trial's blind rating sheet and summary, the curation sheet and reserves, the 40/160 split, and provisional coverage tiers. `uv run python -m src.queries.grid benchmark`; after the notebook, `uv run python -m src.queries.curation sheet`; `translate` prepares and checks the translate-then-search control (decision 0019) |
| `benchmark/` | The fixed judge prompt (UMBRELA-based) and the judging steps: pools, the author's blind pilot sheet, judge-author agreement (weighted kappa), TREC qrels (`uv run python -m src.benchmark.judging pool|pilot|agreement|qrels`). Scores TREC runs against qrels with ir-measures: NDCG@10 and the secondary measures, bootstrap intervals, paired randomization tests with Holm's correction, results by group; refuses test-split runs until the analysis plan is committed. `uv run python -m src.benchmark.evaluate --help`; `tier_analysis` compares a graph and a text system by coverage tier (decision 0031); `interim` assembles the 30 Nov checkpoint report from the generated files; `validation` builds the blind 15-query human validation sheets and their agreement report; `type_coverage` is the descriptive type coverage@10 |
| `graph_retrieval/` | Graph systems: personalised PageRank from linked entities over the core graph, hubs down-weighted (decisions 0007, 0027). `uv run python -m src.graph_retrieval.ppr --seeds Q466581`; `query_seeds` turns a query TSV into the seed file the PageRank runner reads; `features` computes the graph features of ranking: meta-paths, SimRank on candidates, overlap, Horn's index (decision 0036) |
| `retrieval/` | Retrieval systems on corpus v1: the shared passage file and BM25 / BM25+RM3 over per-language Lucene indexes (decision 0023); dense baselines (two MiniLMs, multilingual-e5-large, BGE-M3), encoded on a GPU notebook (decision 0024); `fusion` merges run files by reciprocal rank fusion (k = 60, decision 0008); `entity_bm25` is the entity-expanded BM25 control (decision 0033); `rerank` (bge-reranker-v2-m3, MaxP, via `notebooks/reranker.ipynb`) and `ltr` (LambdaMART, out of fold, SHAP; decision 0037) |
| `2_preprocessing/` … `7_evaluation/`, `fallback/` | Pipeline of the conference version (preprocessing, representation, knowledge graph, ranking, query system, evaluation), to be replaced by the corpus v1 systems |

The numbered folders are inherited; new code goes in folders with descriptive names.
